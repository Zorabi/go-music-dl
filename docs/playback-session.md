# 播放清单与恢复

清单自动保存在当前浏览器或桌面 WebView 的 IndexedDB 中，不按页面大小截断。仅保存歌曲元数据，恢复时重新生成播放地址，不保存临时播放链接或歌词内容。

当前歌曲和进度使用同一站点的 localStorage 保存。播放期间每 5 秒保存一次，暂停、跳转和关闭页面时也会尝试保存。强制终止进程时，进度可能回退到最近一次保存的位置。重启后恢复清单和选中歌曲，保持暂停，由用户点击播放。

打开播放器的播放清单即可：

- 点击每首歌曲右侧的“×”，移除单首歌曲，不会因点击移除而触发播放。
- 点击顶部“清空清单”，确认后停止播放并清除整个清单和保存的进度。
- 移除当前歌曲时沿用播放器的切换规则；移除最后一首则停止播放并保存为空清单。

移除与清空均持久化，重启后不会恢复已移除的歌曲；音乐文件、下载队列和独立播放历史不受影响。保存失败会显示提示。

异步恢复不会覆盖用户已建立的新清单，延迟音频元数据不会把进度应用到另一首歌曲。恢复本身不触发自动下载缓存。

数据按站点和浏览器分别保存，其他浏览器不共享；清除网站数据也会清除此清单。旧版未保存的内存清单无法追溯恢复。
